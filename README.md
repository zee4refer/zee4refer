# Free GST and billing tools for Indian businesses

Open-source helpers for Indian shops, traders and developers building billing software: GST maths, GSTIN checks, HSN codes, amount in words and UPI QR codes.

## Tools

| Repo | What it does | Use it online |
|---|---|---|
| [gst-calculator-india](https://github.com/zee4refer/gst-calculator-india) | Add or remove GST with CGST/SGST or IGST split (JS + Python) | [billingbazaar.in/tools/gst-calculator/](https://billingbazaar.in/tools/gst-calculator/) |
| [gstin-validator](https://github.com/zee4refer/gstin-validator) | Validate a GSTIN offline: state, PAN, check digit (JS + Python) | [billingbazaar.in/tools/gstin-validator/](https://billingbazaar.in/tools/gstin-validator/) |
| [hsn-sac-codes-india](https://github.com/zee4refer/hsn-sac-codes-india) | 446 HSN + 203 SAC codes with Hindi/Hinglish search words (JSON/CSV) | [billingbazaar.in/tools/hsn-code-finder/](https://billingbazaar.in/tools/hsn-code-finder/) |
| [gst-state-codes-india](https://github.com/zee4refer/gst-state-codes-india) | GST state codes of all states and UTs (JSON/CSV) | [billingbazaar.in/tools/gst-state-codes/](https://billingbazaar.in/tools/gst-state-codes/) |
| [amount-in-words-indian](https://github.com/zee4refer/amount-in-words-indian) | Rupees in words with lakh/crore for invoices and cheques (JS + Python) | [billingbazaar.in/tools/amount-in-words-converter/](https://billingbazaar.in/tools/amount-in-words-converter/) |
| [upi-qr-code-generator](https://github.com/zee4refer/upi-qr-code-generator) | UPI payment QR links for any UPI app (JS) | [billingbazaar.in/tools/upi-qr-code-generator/](https://billingbazaar.in/tools/upi-qr-code-generator/) |

More free tools (GST invoice generator, quotation maker, barcode generator, logo maker …): **[billingbazaar.in/tools](https://billingbazaar.in/tools/)**
